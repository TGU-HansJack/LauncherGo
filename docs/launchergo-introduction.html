LauncherGo 是由微尘工作室（Vintage Story CN Studio，VSCN）开发的 Vintage Story 第二代服务器启动器。它把服务端下载、档案管理、配置编辑、进程控制、存档管理、自动化任务、模组和联网工具集中到一个桌面应用中。

使用范围：LauncherGo 管理本机的 Vintage Story 服务端实例和配套服务。实际可用功能会根据已安装的服务端版本、模组和网络工具而变化。

快速开始

  1. 首次启动时设置工作区目录，并下载或导入 Vintage Story 服务端。
  2. 创建一个服务器档案，选择服务端版本，再按需要导入存档。
  3. 在服务器配置中设置基础参数、世界参数和世界规则。
  4. 从主页选择档案和存档，启动服务器并在控制台查看实时日志。

服务器管理

档案、版本与存档

每个档案拥有独立的服务端目录、配置、模组、日志和存档路径。启动器支持服务端版本列表、搜索、下载、缓存清理、压缩包导入，以及档案和存档的创建、导入、删除和刷新。

默认存档可以锁定，避免自动启动时误选其他世界。存档管理还支持使用 Zstandard 压缩节省磁盘空间，并可在压缩完成后按设置处理源文件。

进程与控制台

服务器通过独立的控制通道运行。LauncherGo 可以启动、停止、接管已有进程，并处理 Relay 状态、孤儿进程和启动超时。控制台支持实时日志跟随、命令发送、自定义快捷命令和日志导出。

配置与自动化

服务器配置页面覆盖基础服务器设置、世界创建参数、存档选择和世界规则。世界生成后会自动锁定只能在建档阶段修改的字段；配置保存后会同步写回对应档案。

能力 说明
定时任务 按时间窗口自动开服、关服、备份和广播。
关服前备份 在计划关服前执行备份，并等待备份输出就绪。
日志导出 保存控制台、服务端和自动化运行日志，便于排查问题。

模组与内置服务

模组管理器会扫描 ZIP 模组和目录模组，读取 modinfo.json，展示版本、状态、依赖和问题，并支持启用、禁用、导入和删除。删除操作仅允许作用于当前档案的模组目录。

服务 用途
ServerAuth 提供密码认证、会话记住、Discourse SSO 和 OAuth2/OIDC 授权码认证。
服务器桥接 接收并展示服务器状态、在线玩家和日志。

连接与机器人

连接页面集成常规 FRP、第三方 FRPC、EasyTier、Server Bridge 和 QQ 机器人。网络服务可以按档案配置，机器人支持档案绑定、群号和超级管理员设置，并使用本地数据库保存运行所需数据。

部署提醒：内置模组会在需要时部署到当前服务端档案。部署或升级模组前建议停止正在运行的服务器，并确认服务端版本与模组依赖匹配。

数据与设置

外观、语言、网络目录、下载并发、自动启动、关闭行为、快速命令和压缩策略均可在设置中调整。LauncherGo 支持中文和英文运行时切换，工作区目录可以迁移到适合长期运行和备份的位置。

LauncherGo is the second-generation Vintage Story server launcher developed by Vintage Story CN Studio (VSCN). It brings server downloads, profile management, configuration editing, process control, save management, automation, mod management, and connectivity tools into one desktop application.

Scope: LauncherGo manages local Vintage Story server instances and their supporting services. Available features depend on the installed server version, mods, and network tools.

Getting started

  1. Set the workspace directory on first launch, then download or import a Vintage Story server.
  2. Create a server profile, select its server version, and import a save when needed.
  3. Configure server settings, world settings, and world rules.
  4. Select a profile and save on the home page, start the server, and follow live output in the console.

Server management

Profiles, versions, and saves

Each profile has isolated server, configuration, mod, log, and save paths. The launcher supports server version lists, search, downloads, cache cleanup, archive imports, and creating, importing, deleting, and refreshing profiles and saves.

The default save can be locked to prevent an automatic launch from selecting another world. Save management also supports Zstandard compression to reduce disk usage and can process source files according to the selected policy after compression.

Processes and console

Servers run through an independent control channel. LauncherGo can start, stop, and attach to existing processes, while handling Relay state, orphan processes, and startup timeouts. The console provides live log following, command sending, custom quick commands, and log export.

Configuration and automation

The server configuration page covers common server settings, world creation parameters, save selection, and world rules. Fields that are only valid during world creation are locked after the world has been generated, and saved values are written back to the selected profile.

Capability Description
Scheduled tasks Automatically start, stop, back up, and broadcast according to configured time windows.
Backup before shutdown Runs a backup before a scheduled shutdown and waits until its output is ready.
Log export Exports console, server, and automation logs for troubleshooting.

Mods and embedded services

The mod manager scans ZIP and directory mods, reads modinfo.json, shows versions, status, dependencies, and issues, and supports enabling, disabling, importing, and deleting mods. Deletion is restricted to the current profile's mod directory.

Service Purpose
ServerAuth Provides password authentication, remembered sessions, Discourse SSO, and OAuth2/OIDC authorization-code authentication.
Open information Receives and displays server status, online players, and logs.

Connectivity and bot integration

The connection page integrates regular FRP, third-party FRPC, EasyTier, Server Bridge, and QQ bot services. Network services can be configured per profile. The bot supports profile bindings, group IDs, and super-user settings, with local storage for its runtime data.

Deployment note: embedded mods are deployed to the selected server profile when needed. Stop the running server before deploying or upgrading a mod, and verify that the server version satisfies its dependencies.

Data and preferences

Appearance, language, network catalogs, download concurrency, automatic startup, close behavior, quick commands, and compression policies are configurable. LauncherGo supports switching between Chinese and English at runtime, and the workspace can be moved to a location suitable for long-running servers and backups.
