# LauncherGo 2.6.5

### 新增

- QQ 机器人新增 `/modfile` 和 `/modfileall` 群文件指令，分别打包 Universal 模组和当前档案的全部模组。
- 新增项目版权声明和第三方依赖清单；应用、安装包和独立嵌入模组发布包会携带对应许可证文件。

### 优化

- PDF 导出从 QuestPDF 迁移到 MIT 许可证的 PDFsharp/MigraDoc，保留中文字体、自动分页、页眉和页码支持，消除 QuestPDF 社区版或商业版资格风险。
- 统一程序集作者、公司、产品、版权、GPL-3.0-only 和源码仓库元数据，并在安装程序中展示 GPLv3 许可协议和正确的发布者信息。
- 关于页面新增动态版本、安装包类型、版权和许可证信息，并提供源码仓库及随包版权文件入口。

### 注意事项

- PDF 导出仅在运行时读取 Windows 已安装的等线或黑体，不在 LauncherGo 发布包中分发微软字体文件。
