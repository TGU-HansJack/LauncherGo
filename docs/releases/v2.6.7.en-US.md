# LauncherGo 2.6.7

## QQ Robot

- Added `/bind <game-player-name>` in bound QQ groups. The matching in-game player completes verification by sending the QQ number in server chat.
- Bound users can privately send `/myinfo` for live player name, server, connection state, spawn-relative position, dimension, latency, health, hunger, game mode, online times, and inventory. Permission details are excluded.
- Temporal storm approaching, imminent, and waning announcements are relayed through Server Bridge to bound QQ groups.
- Death messages use the final localized sentence produced by the server Audit log, matching the in-game log.

## Server Bridge

- Added an on-demand `player.info` query for one player's spawn-relative position, health, hunger, and carried inventory.
- Player coordinates now match the spawn-relative values shown in game instead of internal absolute values around 500,000.

## Update Checks

- Automatic update checks at startup report stable releases only.
- The manual settings-page update check also includes prereleases.

## Open Source and Copyright

- Moved LauncherGo and its first-party embedded mods to the MIT License; HansJack remains the project owner.
- Expanded the README with the open-source component list, build and test instructions, copyright, and binary redistribution requirements.
