# LauncherGo 2.6.8-pre.1

## Gateway

- Gateway state snapshots now retry after transient file-lock or I/O failures, preventing live connection and traffic values from getting stuck.
- Removed backend statistics JSONL history snapshots to prevent unbounded log growth.

## UI

- Adjusted the top action-button layout and spacing on the Mods, Authentication, Server Bridge, and Automation pages.
- Hid load-status and configuration-path hints from the configuration editor.
- The first-launch author text now displays as `VSCN-Studio Team`.
- Fixed dangerous buttons shifting when hovered because of changing border dimensions.
