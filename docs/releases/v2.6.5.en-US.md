# LauncherGo 2.6.5

### Added

- Added `/modfile` and `/modfileall` group file commands to package Universal mods or all mods from the bound profile.
- Added project copyright and third-party dependency notices; application, installer, and standalone embedded mod releases now carry the applicable license files.

### Improved

- Migrated PDF export from QuestPDF to the MIT-licensed PDFsharp/MigraDoc while retaining CJK font support, automatic pagination, headers, and page numbers, removing the QuestPDF Community or commercial license eligibility risk.
- Centralized assembly author, company, product, copyright, GPL-3.0-only, and source repository metadata, and added the GPLv3 license and correct publisher information to the installer.

### Notes

- PDF export reads an installed DengXian or SimHei font from Windows at runtime; Microsoft font files are not distributed in LauncherGo packages.
