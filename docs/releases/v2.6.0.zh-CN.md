### 新增

- 发布 LauncherGo 2.6.0，版本号与 Windows 打包及 Release 工作流默认值同步更新。

### 修复

- 移除 OSQ 快照、缓存和 QQ 机器人消费链路中的地图字段，避免继续生成或传播地图数据。

### 优化

- 完整移除 ServerMap/LiveMap 地图模组、部署服务、嵌入资源和相关 UI 配置。
- 清理地图数据导出、存档地图块读取、地图切片生成和地图能力声明，保留服务器状态、玩家、聊天与日志信息上报。

### 注意事项

- LauncherGo 2.6.0 不再内置或自动部署地图模组；现有档案中的相关文件需要管理员自行维护。
