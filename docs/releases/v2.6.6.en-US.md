# LauncherGo 2.6.6

## Server Bridge

- Replaced the OpenServerQuery HTTP path with the local NDJSON Server Bridge for status queries, commands, and event subscriptions.
- Renamed the embedded mod to `launchergoserverbridge` and its assembly to `serverbridge.dll`.
- Bridge configuration now reloads live. Changing enablement or port restarts the local listener automatically.
- Old bridge package files are cleaned up to prevent Vintage Story from rejecting a mod folder containing multiple mod assemblies.

## QQ Robot

- `/server status` now includes world time, season, TPS, average tick time, online players, and recent connection events.
- `/server players` includes player connection state and latency.
- Death messages now include a reason, damage type, and available damage source information.
- Group messages echoed back through server announcements are no longer relayed to QQ a second time.

## Fixes

- Fixed Server Bridge migration work blocking window creation during `dotnet watch run` startup.
- Fixed duplicate player-join notifications in bridge event forwarding.
