### Added

- Released LauncherGo 2.6.0 and synchronized the version with the Windows packaging and Release workflow defaults.

### Fixed

- Removed map fields from the OSQ snapshot, cache, and QQ bot consumption paths so map data is no longer generated or propagated.

### Improved

- Fully removed the ServerMap/LiveMap mod, deployment service, embedded assets, and related UI configuration.
- Removed map-data export, savegame map-chunk reading, map-tile generation, and map capability reporting while retaining server status, player, chat, and log reporting.

### Notes

- LauncherGo 2.6.0 no longer bundles or automatically deploys a map mod. Administrators must maintain any related files already present in existing profiles themselves.
