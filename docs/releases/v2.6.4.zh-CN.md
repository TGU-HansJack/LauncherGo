# LauncherGo 2.6.4

### 新增

- 模组页面新增“导出”按钮和导出配置弹窗，可选择 CSV、PDF、TXT、Markdown、XLSX 格式及需要导出的表格列。
- 导出列默认不包含配置路径和文件路径，并支持导出模组官网链接、依赖、问题和启用状态等完整信息。
- QQ 机器人新增 `/modslist txt|pdf|md|xlsx|csv` 指令；TXT 直接回复文本，其余格式发送为文件。

### 优化

- 模组官网链接通过官方模组 API 解析，优先使用 `urlalias`，并对数字模组 ID 和网络失败场景提供可靠降级。
- PDF 导出使用系统中文字体嵌入，避免中文模组信息在阅读器中显示乱码。
