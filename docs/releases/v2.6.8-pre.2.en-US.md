# LauncherGo 2.6.8-pre.2

## Added

- Added an independent Discord bot integration with Profile, Guild, and Channel bindings, user or role administrator permissions, auto-start, and player binding.
- Added Discord custom slash commands, mod-list exports, and Universal or complete mod archive exports.
- Added a Redeploy Commands action that resets Guild commands without clearing the bot token or server bindings.

## Fixed

- `/server status` and `/server players` now use readable Markdown formatting instead of exposing the raw bridge JSON structure.
- The update dialog now preserves prerelease suffixes such as `2.6.8-pre.1` and compares versions using SemVer precedence.

## Improved

- Discord command descriptions and server status output now follow the bound server's `ServerLanguage`, covering all 22 server language codes with regional fallback.
- Discord and OneBot share basic command parsing and message splitting while keeping configuration, runtime state, and player bindings isolated.
