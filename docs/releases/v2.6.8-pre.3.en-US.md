# LauncherGo 2.6.8-pre.3

## Added

- Added `/tp <point name>` to the QQ bot. Administrators can maintain named X/Y/Z destinations on the OneBot page.
- QQ users bound to a game player can teleport themselves from the corresponding server group. Calling `/tp` without a point name lists the available destinations.

## Improved

- Teleport requests now verify both the QQ player binding and the current group's server binding to prevent cross-server use.
- Point names, duplicates, coordinate ranges, and generated player teleport commands are validated to prevent arbitrary server-command construction.
