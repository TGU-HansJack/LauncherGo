### Added

- Released LauncherGo 2.6.3 and updated the default version in local development builds and release workflows.
- Added an Update column to the mod list and a manual check button for installed mod versions.
- Mod update results and the latest check time are persisted, so the previous state remains visible after refreshing the list or restarting the launcher.
- Added an update dialog showing the current version, latest version, release date, changelog, and homepage, with an Update button.
- The launcher can download and validate the official mod archive, replace the installed mod, and preserve its enabled or disabled state.

### Improved

- Update, Latest, and Check failed states are shown with blue, green, and red status colors for quick scanning.

### Fixed

- Failed updates now attempt to restore the original mod files, reducing the chance of leaving an incomplete installation after replacement.
