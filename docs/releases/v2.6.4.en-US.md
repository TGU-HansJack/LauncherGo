# LauncherGo 2.6.4

### Added

- Added an Export button and export configuration dialog to the mod page, with CSV, PDF, TXT, Markdown, and XLSX support plus selectable table columns.
- Config and file paths are excluded by default, while homepage URLs, dependencies, issues, and enabled state can be exported with the mod list.
- Added the QQ robot command `/modslist txt|pdf|md|xlsx|csv`; TXT is replied as text and other formats are sent as files.
- Added `/modfile` and `/modfileall` group file commands to package Universal mods or all mods from the bound profile.

### Improved

- Mod homepages are resolved through the official mod API, preferring `urlalias` and falling back safely to numeric mod IDs or a network-independent URL.
- PDF exports embed a system CJK font so Chinese mod information renders correctly in PDF readers.
